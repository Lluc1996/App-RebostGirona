# El meu rebost

Llista de tot el que hi ha a casa: foto (feta amb el mòbil), nom i quantitat. Identitat visual Can Colls.

- Toca el **+** de l'esquerra per fer o triar una foto. Toca el nom per editar-lo o eliminar-lo.
- **Afegir una llista**: un producte per línia (`3 llet`, `ous 12`, `-2 iogurts`, `pa`). Si ja hi és, suma o resta; si no, l'afegeix.
- Tot es guarda al navegador (`localStorage`), fotos incloses. Fes servir *Copiar còpia* per passar-ho a un altre dispositiu.

## Publicar a GitHub Pages (gratis)

1. GitHub → **Settings** → **Pages**.
2. *Source*: **Deploy from a branch** · *Branch*: `main`, carpeta `/ (root)` → **Save**.
3. En 1-2 minuts la web és a `https://lluc1996.github.io/app-rebostgirona/`.
